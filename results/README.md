# Experiment results

Commit short result summaries here, not model checkpoints or full prediction files. For each run, record:

- Branch and commit ID
- Hypothesis and the one main change
- Dataset version and split seed
- Model checkpoint and config path
- EM and F1 from `vendor/evaluate-v2.0.py`
- Any optional metrics specific to the experiment
- Hardware, package versions, and exact commands

Do not fill in a baseline score until the baseline has actually been trained and evaluated.
